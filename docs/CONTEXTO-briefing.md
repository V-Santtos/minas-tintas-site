# CONTEXTO — Fase de Briefing (arquivado)
> Este arquivo registra as decisões tomadas durante a fase de briefing e geração do rascunho.
> Fase encerrada em: Maio 2026. O site foi gerado via Claude Design e a estrutura foi reorganizada.

---

## O QUE É ESSE PROJETO
Site apresentativo (folha de rosto) para a **Minas Tintas** — loja física em Simonésia, MG.
Não é e-commerce. Objetivo: apresentar a marca, mostrar linhas de produto com carrosséis, gerar contato via WhatsApp.

---

## VISUAL VALIDADO

- **Estilo:** editorial dark/light alternado (referência: site EcoScape) — maioria das seções em fundo claro
- **Paleta:** base off-white `#F7F5F2`, vermelho da marca `#C8102E` (acento cirúrgico em botões e eyebrows), escuro editorial `#141210`
- **Tipografia:** Fraunces (display/títulos) + Inter (corpo/UI)
- **Eyebrow:** Inter 12px / caps / vermelho / tracking largo — padrão em todas as seções

## DECISÕES DE ANIMAÇÃO (GSAP — acordadas no briefing)
- SplitText em 3 lugares: Hero (words), Divisor (lines), Texturas (lines)
- Footer sem animação
- Cards do scroll-cards: componente gerencia internamente
- Faixas de textura: opacity only, sem deslocamento vertical
